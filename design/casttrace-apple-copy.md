# CastTrace Android 界面文案

## 直播间

- 标题：`直播间`
- 副标题：`监控开播状态与录制任务`
- 规则标题：`自动录制的条件`
- 规则表达：`全局自动录制 + 房间开关`
- 规则说明：`两项都开启后，主播开播时才会自动保存。`
- 空状态标题：`先添加一个直播间`
- 空状态说明：`粘贴直播地址后，CastTrace 会开始检查开播状态。`
- 主操作：`添加直播间`
- 搜索入口：`搜索直播间`

## 开播提醒

- 标题：`开播提醒`
- 副标题：`关注主播，开播时通知你`
- 权限状态：`通知权限未开启`
- 权限说明：`开启系统通知后，主播开播时会提醒你。`
- 权限操作：`去设置`
- 空状态标题：`还没有关注的主播`
- 空状态说明：`添加主播，或从已有直播间导入。`
- 主操作：`添加主播`
- 次操作：`从直播间导入`

## 视频库

- 标题：`视频库`
- 副标题：`已保存的直播录制`
- 搜索提示：`搜索主播、标题或日期`
- 筛选入口：`筛选`
- 列表标题：`全部录制`
- 空状态标题：`还没有录制文件`
- 空状态说明：`完成的直播录制会保存在这里。`
- 功能说明：`已保存的视频可以播放、分享，也可以导出带弹幕版本。`
- 主操作：`前往直播间`

## 设置

- 页面副标题：`录制偏好与后台运行`
- 分组：`录制默认值`、`后台运行`、`通知与外观`
- 录制默认值：`保存目录`、`默认格式`、`默认清晰度`
- 后台运行：`全局自动录制`、`后台持续检测`、`电池优化`
- 通知与外观：`系统通知`、`外观`
- 全局自动录制说明：`开播后自动开始录制`
- 后台持续检测说明：`离开应用后继续检查开播状态`
- 其他入口：`存储管理`、`备份与恢复`、`平台适配`、`使用说明`

## 交互约定

- 页面为空时隐藏没有可操作对象的状态筛选；添加内容后再显示筛选与列表操作。
- 自动录制需同时开启全局自动录制与对应直播间的开播自动录制。
- 后台持续检测只控制应用离开前台后是否继续检查开播状态，不代表所有房间都会自动录制。
- 视频库空状态仍展示搜索和筛选入口，文案说明可用操作，避免把筛选误认为只能从其他页面进入。
- 设置页的开关状态是设计示意；实际展示与交互应绑定用户当前配置。
- 横屏时减少上下留白并重排内容，底部主导航仍沿屏幕边缘显示；竖屏使用同一导航栏，不悬浮、不遮挡内容。
